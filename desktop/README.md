# 时遇 Windows

基于仓库 `web/` 的 Windows 10 / 11 64 位桌面客户端。安装包内置界面、图标和 Electron 运行时，不需要安装 Node.js、Java 或单独启动浏览器。

## 使用

运行 `release/windows/Shiyu-0.2.7-win-x64-Setup.exe`，按中文向导选择安装位置。默认安装到当前用户目录，不要求管理员权限，同时创建桌面和开始菜单快捷方式。

- 在设置中填写自己的 OpenAI 兼容接口、API Key 和模型。
- 本地角色卡、聊天、世界书、朋友圈、备份等复用 Web 版本。
- 断网可打开界面和查看已保存内容；远程模型、角色广场、登录、云同步和未下载的本地模型仍需要网络。
- 支持 HTTPS 模型地址，以及 `http://localhost:端口`、`http://127.0.0.1:端口` 本机接口。其他 HTTP 地址受混合内容安全策略限制。
- 登录使用独立窗口，沿用现有云端账号。登录后沿用 Web 端同步规则，包括模型配置；请只登录自己的账号。
- 菜单可开启“关闭窗口时最小化到托盘”，默认关闭窗口即退出。应用未运行时不会发送主动消息。
- 数据保存在 `%APPDATA%\Shiyu`。默认卸载和覆盖安装保留数据；重要数据请在设置里另行导出备份。
- 启动后自动检查新版本，每 4 小时再次检查；发现新版本时发送 Windows 系统通知，可在“设置 → 关于与更新”下载并重启安装。
- 不会自动读取 Chrome、Edge 或安卓版的数据。可使用现有 JSON 备份导入功能或账号同步迁移。

这不是安卓 APK 的完整原生移植。安卓专属后台服务、无障碍、原生本地推理组件和系统悬浮桌宠尚未移植；桌宠仍是应用内版本。本地模型功能沿用 WebGPU 方案，需要兼容显卡。

目前未配置 Windows 代码签名证书，安装包可能显示“未知发布者”或 SmartScreen 提示。仅从可信渠道安装，并核对提供的 SHA-256。正式公开分发建议先签名。

## 构建

在 `desktop` 目录使用 Node.js 22 或更新版本：

```powershell
npm ci
npm run dist
npm run test:smoke
```

`npm run start` 启动开发版；`npm run pack` 仅生成解包程序。

构建脚本读取 `web/`，只复制明确列出的运行资源，不修改 Web 源文件，不打包安卓安装包、服务端凭据或签名密钥。图标复用现有品牌素材，Lucide 固定版本本地打包。`renderer/source-manifest.json` 记录源文件散列以追溯版本。

安装包输出到 `release/windows/`。桌面端不改变任何线上域名、Cloudflare 路由或官网部署。官网发布仍须使用 `shiyu-official` 项目。

## 验证

`npm test` 检查资源白名单、导航边界、CORS、OAuth 转发和窗口位置恢复。`npm run test:smoke` 使用独立临时用户目录启动真正的 Electron 客户端，测试本地启动、界面导航、无 CORS 的本机模拟模型、数据持久化和截图。不会使用真实 API Key 或产生模型费用。
