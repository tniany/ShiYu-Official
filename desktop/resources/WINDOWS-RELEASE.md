# 时遇 Windows 0.2.7

适用于 Windows 10 / 11 64 位（x64）。

## 下载与安装

下载 `Shiyu-0.2.7-win-x64-Setup.exe`，运行后按中文向导选择安装目录。包含运行环境、桌面和开始菜单快捷方式、卸载程序，无需另外安装 Node.js、Java 或浏览器。

官网下载页：https://shiy.tniay.top/download/

网页版下载页：https://web-shiy.tniay.top/download/

## 本版更新

- 增加启动后自动检查、每 4 小时定时检查、Windows 系统通知、下载进度和重启安装。
- 更新源为 `https://web-shiy.tniay.top/downloads/windows/latest.yml`，支持覆盖安装并保留本地数据。
- 保留并修复 Windows 中文输入法在聊天输入框确认候选词时被误判为发送的问题。

## 功能

- 复用时遇 Web 的角色卡、聊天、群聊、世界书、正则和朋友圈功能。
- 支持自定义模型接口、本机接口与 JSON 数据备份。
- 提供独立桌面窗口、可选托盘常驻；断网可查看本地内容。
- 本地数据位于 `%APPDATA%\Shiyu`，默认覆盖安装和卸载均保留数据。
