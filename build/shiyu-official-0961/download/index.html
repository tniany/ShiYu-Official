本版复用时遇 Web 核心功能，不是安卓版全部原生能力的完整移植。

常见问题

下载之前，你可能想知道。

旧设备的聊天记录怎么迁移？

可通过原有账号同步，或在旧端导出兼容的 JSON 数据备份，再在电脑版的「设置 → 数据与隐私」中导入。请先保留一份原始备份。电脑版不会自动读取浏览器或手机中的数据。

卸载或更新会删除聊天记录吗？

默认覆盖安装和卸载会保留本地数据，目录为 %APPDATA%\Shiyu。重要记录建议定期导出独立备份。

不联网也能使用吗？

界面与图标内置在安装包中，断网可以打开并查看本地内容。远程模型、角色广场、登录、云同步及尚未下载的模型仍需要网络。

支持 Windows ARM、32 位或 Windows 7 吗？

当前安装包仅面向 Windows 10 / 11 x64，不提供 32 位、原生 ARM64 或 Windows 7 / 8 版本。其他设备可以使用 Android 版或网页版。
