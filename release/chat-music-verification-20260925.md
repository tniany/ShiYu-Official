# 时遇对话与听歌修复验证

安装包：`shiyu-0.9.3-chat-music-20260925.apk`

版本仍为 0.9.3（versionCode 59），使用现有发布签名，未上传或发布到更新服务。

## 本次处理

- 接通 MCP 调用通知，在对话设置增加独立开关；工具指令和流式指令片段不再直接展示在角色正文中。
- 调整角色陪伴提示，强调人设、已有关系、情绪与叙事连续性，工具作为可选能力。
- 修复图片消息重复组装、空占位进入请求、工具通知挤占历史窗口，以及裁剪误删当前用户消息。
- 主聊天、后台主动消息和桌宠回复共用有效消息筛选；超出可保留的上下文时明确报错，不发送丢失本轮消息的请求。
- 支持移除一起听成员，包括当前角色和最后一个角色；移除后不会因自动切歌而重新加入。
- 自动切歌和循环播放不追加音乐卡片；重复进入同一首歌去重，当前听歌场景单独注入。
- 修复快速切歌旧请求抢播、加载中反复点击播放器、手动暂停后音频焦点误恢复等相关状态问题。
- 修复语音通话回复提前返回、自动生图进度参数为空，以及第三方音乐链接携带网易云 Cookie 的问题。
