# 时遇 0.9.6.1 补充更新

本版本是 0.9.6 的补充更新，0.9.6 已发布的市场、默认玻璃材质与稳定性修复保持不变。

## 本次补充

- 市场支持从本地导入自定义主题与插件。
- 本地导入前会显示不可跳过的 5 秒安全提醒。
- 本地插件只调用 App 已实现并审核的接口，不加载脚本或远程代码。
- “关于时遇”新增开源仓库入口。
- “关于时遇”新增插件与主题开发文档入口。
- “关于时遇”新增 Discord 社区入口，邀请地址为 `kpGgDXpGg`。

## 下载

- Android 0.9.6.1：`shiyu-0.9.6.1.apk`
- Windows 0.2.7：`Shiyu-0.2.7-win-x64-Setup.exe`

官网下载入口会记录点击后跳转到 GitHub Release。下载统计同时汇总官网跳转次数和 GitHub Release 资产下载次数。
