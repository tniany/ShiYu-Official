# 时遇 0.9.3

发布日期：2026-09-25

- 缩小底部导航图标与文字的间距，保持标签清晰紧凑。
- 在“会话 → 对话设置 → 对话模型”中直接新增和编辑模型供应商，保存后返回当前会话的模型设置。
- 完善 JSON、SHIY、PNG 角色卡的外部“分享”和“用其他应用打开”入口。
- 支持只通过 ClipData 提供文件的分享方式；多文件分享依次进入预览，由用户逐个确认或取消。
- 修复对话流式读取异常后持续转圈、超时无回复的问题。
- 保留横竖屏切换时的当前页面，并修复底部按钮遮挡。
- 底部导航滑到底部时以粒子消散效果隐藏，回滑时聚合恢复。
- 修复历史数据较大时启动进入数据抢救页面的问题，并保留可恢复能力。
- 修复正常对话超时无回复、流式连接提前关闭后后台持续空转的问题。
- 新增默认角色卡“林晚星”。
- 角色可按需调用内置工具、已启用的 MCP 服务和视频生成工具；推荐 MCP 页面不再展示逐次确认提示。
- 支持视频生成模型及独立供应商配置、视频任务查询下载和加入当前会话。
- 支持按内容勾选导出备份。
- 完善 JSON、SHIY、PNG 角色卡的多文件分享、ClipData 附件、重复地址去重和失败后继续处理。

安装包：`shiyu-0.9.3.apk`

应用标识：`com.tniany.shiyu`；内部版本号：59。正式版使用现有发布签名，关闭调试模式，支持覆盖安装并保留本地数据。
