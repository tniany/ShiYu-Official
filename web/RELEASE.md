# 时遇 Web 1.4.0

正式版目标为 Android 版约 70–80% 的核心功能覆盖，优先保证本地数据安全、主要流程完整和桌面/移动端可用。

## 启动

Windows 用户双击 `start.bat`，浏览器会自动打开 `http://localhost:4173/`。关闭启动窗口即可停止服务。

如果 4173 端口被占用，可在 PowerShell 中运行：

```powershell
.\start.ps1 -Port 4174
```

Chrome 或 Edge 可通过地址栏右侧的安装按钮把它安装为独立窗口应用。

## 已包含

- 角色卡创建、编辑、JSON/PNG 导入导出与草稿恢复
- 单聊、群聊、会话搜索、归档、摘要、长期记忆与多种聊天消息
- 多模型供应商配置、模型列表获取与会话级模型切换
- 世界书和正则可视化编辑、角色级与会话级覆盖
- 朋友圈发布、评论、点赞、角色动态和权限控制
- 数据备份、恢复预览、恢复快照和诊断导出
- 小世界基础玩法、音乐、共同活动和网页桌宠
- 酒馆前端安全沙箱显示、自定义拍一拍文案
- 家园头像尺寸修复与手机端紧凑双列布局
- CF OAuth 独立窗口登录、侧边栏云端同步入口与登录状态提示
- 个人中心、QQ 头像、账号资料与聊天/角色/朋友圈/规则云端同步状态
- 手机端全屏按钮、沉浸布局和安全区适配
- 桌面和手机聊天区固定高度，历史消息在会话区域内滚动

## 浏览器限制

- Android 后台服务、系统悬浮窗、无障碍和原生通知常驻能力不能在普通网页中完全复刻。
- 依赖网页保持打开的主动消息、语音和自动活动可能受浏览器节流影响。
- 数据默认保存在当前浏览器本地；正式使用前建议在设置中定期导出安全备份。
