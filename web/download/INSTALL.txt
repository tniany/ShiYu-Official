时遇 Windows 电脑版 0.2.7

系统要求：Windows 10 / 11，64 位（x64）。

安装：
双击 Shiyu-0.2.7-win-x64-Setup.exe，按照中文向导选择安装位置。
不需要另外安装 Node.js、Java 或浏览器。
安装完成后可通过桌面或开始菜单中的“时遇”启动。

使用：
在“设置”中配置自己的模型接口、API Key 和模型。
支持 HTTPS 接口，以及 localhost / 127.0.0.1 的本机 HTTP 接口。
可导入角色卡和 JSON 备份，也可通过原有账号登录云端。
断网可以打开界面和查看本地记录，远程模型和云端功能仍需联网。
启动后会自动检查更新；可在“设置 > 关于与更新”中手动检查、下载并重启安装。

数据：
本地数据目录为 %APPDATA%\Shiyu。
默认覆盖安装和卸载均保留本地数据。
重要聊天请定期在“设置 > 数据与隐私”中导出备份。
默认关闭窗口会退出，可在“时遇”菜单中启用最小化到托盘。

版本范围：
此版本复用时遇 Web 核心功能，并非安卓全部原生功能的完整移植。
安卓专属后台服务、无障碍和系统悬浮桌宠暂未移植。

签名说明：
当前安装包尚未进行 Windows 代码签名，可能提示“未知发布者”。
请仅安装可信来源的文件。SHA256SUMS.txt 提供此安装包的校验值。

卸载：
在 Windows“设置 > 应用”中找到“时遇”，选择卸载。
